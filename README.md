# Javergae-Prompt-Driven-API

Welcome to the **Javergae** experimental lab. This repository demonstrates the power of **Videocoding** and AI-assisted development to build a functional RESTful API from scratch.

## 🚀 Project Overview

The goal of this project is to showcase the workflow of an expert developer using code agents and strategic prompting. Instead of manual coding, the logic and structure were generated through iterative prompts, documenting the transition from a simple console application to a robust Web API.

## 📁 Content
- **/prompts**: 
    - `console-logic-prompts`: Core logic and business rules.
    - `database-integration-prompts`: Database schema design, ORM setup, and persistence prompts.
    - `web-api-prompts`: Transformation into a RESTful service.
- **/src/v1-console-app**: The initial iteration focusing on core business logic and data handling.
- **/src/v2-web-api**: The final iteration transformed into a fully functional RESTful service.
